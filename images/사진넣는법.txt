[사진 넣는 법]

이 images 폴더에 아래 이름으로 사진을 넣으면, 페이지의 "사진 자리"에 자동으로 들어갑니다.
확장자는 jpg / jpeg / png / webp 모두 됩니다. (예: banner-recruit.png)

  profile        Profile 페이지 - 프로필 사진 (세로 3:4 권장)

* 프로젝트 상세의 "현장 기록" 사진 칸은 없앴습니다. 프로젝트에는 아래 대표 사진만 씁니다.
* GitHub Pages는 대소문자를 구분합니다. 파일 이름은 위와 똑같이 소문자로 써 주세요.
